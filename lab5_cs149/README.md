# Лабораторная работа №5 (CS149)

## Программа 1: Параллельная генерация фракталов (Мандельброт)

### Описание
В рамках работы была исследована параллельная генерация множества Мандельброта с помощью библиотеки `std::thread`. 
Реализована пространственная декомпозиция задачи (разделение изображения между потоками).

### Улучшение алгоритма
Изначально изображение делилось на горизонтальные блоки (полосы). Это приводило к дисбалансу нагрузки (верхняя часть фрактала считается быстрее нижней).
Было применено **циклическое распределение строк** (Interleaved). Каждый поток обрабатывает строки `threadId, threadId + numThreads, ...` Это позволило равномерно распределить нагрузку.

### Результаты экспериментов

### Выводы
1. Распараллеливание позволило почти в 2 раза сократить время генерации фрактала.
2. Использование циклического распределения строк (Interleaved) устранило проблему дисбаланса нагрузки, характерную для статического деления на блоки (аномалия с 3 потоками).
3. Дальнейший рост потоков (4, 6, 8) не дает прироста производительности из-за ограничений аппаратного обеспечения тестовой среды (2 физических ядра). На 4-ядерных процессорах с Hyper-Threading ожидается линейное ускорение до 7-8x.
