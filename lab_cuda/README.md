# Лабораторная работа №1 (CUDA)

Перемножение квадратных матриц с использованием технологии NVIDIA CUDA.

## Результаты экспериментов

| Размер | Блок (TILE_SIZE) | Время (мс) |
| :--- | :--- | :--- |
| 256x256 | 16x16 | 0.1557 |
| 256x256 | 32x32 | 0.1543 |
| 512x512 | 16x16 | 0.7892 |
| 512x512 | 32x32 | 0.7731 |
| 1024x1024 | 16x16 | 5.8601 |
| 1024x1024 | 32x32 | 3.8234 |
| 2048x2048 | 16x16 | 26.0478 |
| 2048x2048 | 32x32 | 39.1617 |

## Верификация
Максимальная ошибка при сравнении с NumPy: 0.000000 (ВЕРИФИКАЦИЯ ПРОЙДЕНА).

## Выводы
1. CUDA позволяет эффективно распараллелить умножение матриц. 
2. Для матриц среднего размера (1024x1024) блок 32x32 показывает лучшую производительность за счет эффективного использования разделяемой памяти.
3. Для больших матриц (2048x2048) блок 16x16 оказался быстрее (26 мс против 39 мс). Блок 32x32 (1024 потока) потребляет много ресурсов, что снижает Occupancy (заполняемость) и не позволяет видеокарте запустить достаточно блоков для полной загрузки.
