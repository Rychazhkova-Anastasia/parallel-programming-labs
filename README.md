# Лабораторная работа №1
## Перемножение квадратных матриц

### Описание
Программа на C++ умножает две квадратные матрицы, считывая их из файлов, и сохраняет результат в файл.

### Структура проекта
```text
parallel-programming-labs/
├── лаборатория1/
│   ├── src/
│   │   └── main.cpp
│   ├── input/
│   │   ├── matrix_a.txt
│   │   └── matrix_b.txt
│   └── output/
│       ├── result.txt
│       └── info.txt
├── verify.py
└── README.md
```
